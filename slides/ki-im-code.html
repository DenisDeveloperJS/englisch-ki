Geschichte · Anfänge

Von Regelwerk
zu neuronalem Netz.

1950–1980

Regelbasierte
Systeme

Hartcodierte Regeln, einfache Autocompletion. Keine echte Intelligenz — nur Muster.

1990–2010

Machine
Learning

Modelle lernen aus Code-Repos. Erste Bugfinding-Tools, statistische Vervollständigung.

2021–heute

Large Language
Models

GPT-3, Codex, GitHub Copilot — KI schreibt vollständigen Code in Echtzeit.

Vortragende:rAbschnitt 01
Geschichte · Meilensteine

Die entscheidenden Momente.

2021

GitHub Copilot

Erste KI direkt im Editor. Echtzeit-Vervollständigung ganzer Funktionen.

2022

ChatGPT

Entwickler nutzen Chat-KI massenhaft für Debugging und Code-Generierung.

2023

Cursor & Co.

KI-first IDEs. Der Editor selbst denkt mit, schreibt ganze Features.

2024–25

Agenten

KI plant, schreibt, testet, deployt — mit minimalem menschlichem Eingriff.

Anwendung · Einsatzbereiche

Wo KI den Alltag verändert.

Im Editor

  • Code-Vervollständigung in Echtzeit
  • Ganze Funktionen aus Kommentaren
  • Refactoring auf Knopfdruck
  • Fremden Code inline erklären

Im Prozess

  • Automatisches Code Review
  • Testfälle aus bestehendem Code
  • Dokumentation automatisch schreiben
  • Bugs aus Stack Traces lokalisieren

Vortragende:rAbschnitt 03
Risiken · Überblick

Stärken und Schwächen.

[OK] Was KI gut kann

  • Boilerplate schnell schreiben
  • Bekannte Muster reproduzieren
  • Dokumentation generieren
  • Fremden Code erklären

[ERR] Was KI schlecht kann

  • Sicherheitslücken zuverlässig vermeiden
  • Komplexen Kontext vollständig verstehen
  • Veraltetes Wissen selbst korrigieren
  • Domänenlogik ohne Kontext erfassen
Vortragende:rAbschnitt 03
Risiken · Konkrete Probleme

Worauf man achten muss.

WARN: SECURITY

Sicherheit

KI-Code enthält messbar häufiger SQL-Injections, unsichere Defaults und veraltete Kryptographie.

WARN: TRUST

Blindes Vertrauen

KI wirkt immer selbstsicher — auch bei falschen Antworten. Code muss immer verstanden werden.

WARN: SKILL

Abhängigkeit

Wer Code nur noch annimmt, verliert langfristig die Fähigkeit ihn zu debuggen und zu verstehen.
