Approach 03 · Automation

Under the Hood: Skills & Custom Workflows.

WARN: EFFICIENCY

Repetitive prompts every day — GitLab creds, company rules, summaries.

What are Skills?

  • Pre-defined, packaged instructions & capabilities
  • Bundle rules, credentials, and tasks once — reuse forever
  • Triggered by a single /slash-command in the editor
review-code.md
---
name: review-code
description: Review current file with our team rules
---

# Coding Rules
- Indentation: 2 spaces, no tabs
- Max line length: 80 characters
- No var — use const / let
- Functions must have a return type

# Review Focus
- Security: no hardcoded secrets
- Performance: avoid unnecessary loops
- Readability: clear naming, no magic numbers

# Output Format
Rate each issue: [critical] / [warning] / [hint]

Approach 03 · Going Further

Skills can call each other._

// SKILL_CHAIN
review-code.md
name: review-code
...
# Final Step
After the review is done,
run /improve-code to apply the fixes.
AI jumps automatically ↓
improve-code.md
name: improve-code
...
# Rules
Apply the fixes from the review.
Keep functions small, names clear.
✓ reviewed + fixed — one command
// HOW IT WORKS
  • One skill calls another — the AI follows the chain automatically
  • Build multi-step workflows triggered by a single command
  • Each skill stays focused on one job — easy to update

You can even spawn multiple sub-agents in parallel — each with its own context, working on the same task — and get one combined output at the end.
